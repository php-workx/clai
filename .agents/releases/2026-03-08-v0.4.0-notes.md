# clai v0.4.0

**clai** is an intelligent terminal assistant that brings Claude into your shell.

## Highlights

- Type a command prefix and see inline ghost-text suggestions drawn from your history, scored by recency, frequency, and context
- Accept, dismiss, or browse suggestions with a visual picker — works in Zsh, Bash, and Fish
- A background gRPC daemon keeps suggestions fast without blocking your shell startup
- Multi-step workflow engine lets Claude reason through complex tasks with human approval gates
- Adaptive learning reranks suggestions based on what you actually use

## What's New

**Shell integration** — `clai install` adds a lightweight hook to your shell. Ghost-text suggestions appear as you type; arrow keys and Tab navigate the picker. All three major shells (Zsh, Bash, Fish) are supported with feature parity.

**Suggestion engine** — Commands are normalized into templates, scored across multiple signals (transition probability, frequency, prefix match, project context), and ranked in real time. A V2 scorer adds full-text search, template discovery, and online weight learning from accept/dismiss feedback.

**Workflow engine** — Define multi-step command sequences with conditional branching, failure recovery, and human approval gates. Claude analyzes command output at each step to decide the next action.

**Voice input** — Speak a command description and clai translates it into the right shell command.
